# Agentic AI Portfolio

A growing collection of agents I'm building as I move deeper into agentic AI systems — coming from a background in Quality Engineering leadership.

Each project here is treated as a standalone, portfolio-ready artifact: the workflow itself, the design decisions behind it, the prompts used, and honest notes on what worked and what didn't.

## Why this repo exists

I lead quality for complex systems, and agentic AI changes what and how we validate. Rather than only reading about it, I'm building small, focused agents — one at a time — and publishing each one so the learning is legible and reusable.

## Projects

| # | Agent | What it does | Stack |
|---|-------|--------------|-------|
| 01 | [Message Routing Agent](./01-message-routing-agent) | Classifies unstructured inbound messages (Demo / Support / Spam), extracts structured fields, and logs each to the right destination | n8n, OpenAI (GPT-4.1-mini), Google Sheets |

More coming — one project per week.

## How I think about each build

Every agent in this repo follows the same lens:

1. **Concept** — the design pattern or capability the agent demonstrates
2. **Build** — the working workflow, importable and runnable
3. **Reflection** — what I learned, especially from a quality / validation perspective
